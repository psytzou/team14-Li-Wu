# Team 14 — Chess Battle

A Unity 6000.3.22f1 game prototype with a grid-based battlefield, player and enemy combat, health displays, action indicators, enemy spawning, kill tracking, and restart/back navigation.

## Play online

https://psytzou.github.io/team14-Li-Wu/

## Unity project

Open the repository root with Unity 6000.3.22f1. The build scenes are ordered as:

1. `Assets/Scenes/gaming_scene.unity`
2. `Assets/Scenes/SampleScene.unity`

The deployable WebGL build is stored in `docs/` for GitHub Pages.
